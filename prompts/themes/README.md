# Theme packs

One file per universe the student can pick in the morning survey. The file
name without `.md` is the theme slug written into `state/today.md`.

A pack exists so the tutor decorates from a fixed vocabulary instead of
improvising, which keeps the decoration consistent across subjects and stops it
drifting into invented lore presented as fact.

| Pack | Slug | Status |
|---|---|---|
| Star Wars | `star-wars` | Written — use it as the template |
| Minecraft | `minecraft` | To write |
| Football | `football` | To write |
| Cars and racing | `cars` | To write |
| Marvel | `marvel` | To write |

`своє` is always an option in the survey. When he names something with no pack,
the tutor decorates from what it knows and the theme slug is recorded as free
text — if the same free-text theme shows up three times, write it a pack.

## What a pack contains

| Section | Purpose |
|---|---|
| Vocabulary | Objects, units and names that can appear in problem statements |
| Ready framings | One or two per subject, so the tutor has a starting shape |
| «Міф чи фізика?» seeds | Scenes from the universe that a textbook law can be checked against |
| Do not | Things that break rule 2 of `docs/engagement-system.md` §1 |

## The rule every pack repeats

Decoration must never add a step to the problem. If the student has to know
what a hyperdrive is before he can find the ratio, the pack has been used
wrongly — state the problem plainly instead.
