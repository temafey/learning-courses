# Reward catalogue

Parent-owned. The tutor may read this file and may never name anything that is
not in it.

Every item needs a price in points and a budget band before it counts as
approved. An item with an empty price is not offerable — the tutor treats a
blank price as "not in the catalogue".

**Prices below are placeholders.** Set them after two weeks of real logs, when
the daily point range is known — see `tasks/16-calibration-window.md`. A price
guessed now is either trivially cheap or unreachable, and both kill the
mechanism in the first week.

## Budget bands

| Band | Ceiling per item | Notes |
|---|---|---|
| S | | Everyday, claimable most days |
| M | | Weekly tier |
| L | | Monthly |
| XL | | Quarterly, one per term |

Fill the ceilings in your own currency. Nothing in the system reads them — they
exist so the catalogue stays inside a budget you decided once, calmly, rather
than one item at a time under negotiation.
